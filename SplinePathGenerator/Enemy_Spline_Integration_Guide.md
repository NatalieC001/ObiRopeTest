# Enemy Spline Integration Guide

This document explains how to use the paths generated by the **Spline Path Generator** with your existing creatures and targets.

## 1. What Does the Generator Output?
The tool creates a Prefab containing two things:
1. `Dreamteck.Splines.SplineComputer`: The actual path/curve.
2. `PathSpawnInfo`: A simple script containing metadata (Enemy Type, Spawn Count, Speed, and whether the path is Open/Closed).

**Note:** The prefab does *not* do anything on its own. It is just data waiting to be read.

---

## 2. Reading the Data in Your Game
Because the enemies are now **baked directly into the prefab** by the Editor Tool, you do not need to write complex logic to spawn them at runtime.

If you have a script that spawns a wave of enemies (e.g., `TrainingLevelManager`), you simply Instantiate the generated Prefab.

```csharp
public void SpawnWaveFromPath(GameObject pathPrefab)
{
    // The prefab already contains the SplineComputer, the Enemy clones,
    // and the configured SplineFollower components!
    Instantiate(pathPrefab, spawnPosition, Quaternion.identity);
}
```

---

## 3. Boss Attack Vector Example (Swapping Paths)

You requested a specific flow for a boss using an "Open Path" (like a spiral or wave) for an attack run, starting at the boss and ending at the player.

Here is the exact logic sequence your boss script (e.g., `BossController`) needs to execute when entering attack mode:

### Step 1: Load the Attack Path
Select an "Open" path prefab that was generated by the tool.

### Step 2: Instantiate a Runtime Copy
```csharp
GameObject attackPathObj = Instantiate(attackPathPrefab);
SplineComputer attackSpline = attackPathObj.GetComponentInChildren<SplineComputer>();
```

### Step 3: Align START to Boss and END to Player
You must shift the points of the spline so they fit the current game state.

```csharp
SplinePoint[] points = attackSpline.GetPoints();

// The total size/length of the original shape
Vector3 originalStart = points[0].position;
Vector3 originalEnd = points[points.Length - 1].position;
Vector3 originalDirection = (originalEnd - originalStart).normalized;
float originalLength = Vector3.Distance(originalStart, originalEnd);

// The new desired positions in the game world
Vector3 bossPos = this.transform.position;
Vector3 playerPos = player.transform.position;
Vector3 newDirection = (playerPos - bossPos).normalized;
float newLength = Vector3.Distance(bossPos, playerPos);

// Calculate rotation and scale differences
Quaternion rotationToApply = Quaternion.FromToRotation(originalDirection, newDirection);
float scaleMultiplier = newLength / originalLength;

// Apply the transformation to every point on the spline
for(int i = 0; i < points.Length; i++)
{
    // 1. Move point to origin relative to the old start
    Vector3 localPos = points[i].position - originalStart;

    // 2. Scale the shape to reach the player
    localPos *= scaleMultiplier;

    // 3. Rotate the shape to point at the player
    localPos = rotationToApply * localPos;

    // 4. Move the point to the boss's actual world position
    points[i].position = bossPos + localPos;
}

// Save the modified points back into the runtime spline
attackSpline.SetPoints(points);
```

### Step 4: Swap and Clean Up
```csharp
// Destroy the boss's old ambient paths
Destroy(currentAmbientPathObj);

// Assign the boss to the new attack spline
SplineFollower follower = GetComponent<SplineFollower>();
follower.spline = attackSpline;
follower.SetPercent(0); // Start at the beginning (boss pos)
```

The boss will now ride the custom mathematical shape, beginning exactly where it is currently standing, and ending exactly where the player was standing when the attack began.
